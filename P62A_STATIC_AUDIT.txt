P62A STATIC AUDIT — PERSISTENT UJ CONTROL GETTER

Functional delta over P60/P61 baseline:
- REMOVE/DO NOT INSTALL P61 F58 eligibility override.
- ADD one trampoline at native control getter main+0x7C6280.
- For native selector8 only:
  * call original getter first;
  * preserve every non-zero native result;
  * when raw==0, identify actor only by exact control_object == actor+0x228 relationship;
  * validate current actor identity is generic custom ID 281..0xFFF;
  * require exact source me_enable_control self/UJ semantic to be registered;
  * return 1 without writing actor state.
- Matching source disable clears only the private semantic registry.
- P60 one-shot native enable setter remains as backing-state alignment, but it is not the persistence mechanism.

Security/scope:
- Vanilla actors: untouched.
- Other native control selectors: untouched.
- Untracked control objects: untouched.
- Native non-zero selector8: untouched.
- No F58 eligibility override.
- No e94/e9c writes.
- No PlayAction/action remap.
- No char==281 gameplay special case.
- Victim-UJ visibility/control shadows retained.

Why this is narrower than P61:
P61 bypassed an eligibility return under a guessed runtime caller guard and never fired in hardware. P62 does not alter eligibility. It implements the missing persistent semantics at the already-proven native control API boundary. If the UJ router reaches selector8, it will observe the source-enabled value; if the router never queries selector8, P62 logs nothing and proves the failure is still farther upstream.
