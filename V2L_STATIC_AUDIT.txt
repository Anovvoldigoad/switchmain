B) Custom assets requested but open fails -> CPK/path/packaging boundary.
C) Assets open but live object graph stays on old environment -> missing environment teardown/rebind lifecycle.
D) Object graph rebinds but battle geometry persists -> render visibility/scene ownership frontier.
