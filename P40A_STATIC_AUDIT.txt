P40A STATIC AUDIT
=================
Parent gameplay baseline: P39A O14 actor-local parity candidate.
P40A introduces NO new gameplay mutation relative to P39A.

Inherited gameplay semantics:
- O14 me_enable_control candidate = actor-local control block +0x12A24, enable=1.
- O12 visibility stays shadow/no-op.
- O15 disable_control stays shadow/no-op.
- O2 StageMove, O3, O4, O8, O13, O22, O23 unchanged.
- valid unported custom Event236 opcodes shadow/no-op.
- vanilla charID <=280 remains native; custom route is generic >280 && <0x1000.

   - traces mode and actor state +0xEA0/+0xEA4/+0xEA8 and +0x1238 pointer.
   - the historical 0x7E13E4 and 0x7E1404 sites are inside this function.

Focused Event236 tracing:
- P40A logs every valid custom opcode 1..29 (cap 2048) so one pure Kamui
  attempt can be reconstructed without preselecting an opcode.

Decision logic:
- victim-UJ PASS + CTRL14_DIRECT boolean old/wrote values => P39/P40 O14 parity candidate survives.
- awakening attempt with no EVT13_AWAKE => failure occurs before native awake-condition event.
- EVT13_AWAKE present but no relevant EVT121_COND => branch between awake-condition and condition-name path.
- EVT121_COND with MTOB names that native cannot resolve => next build can implement generic compiler-data alias bridge.
- Kamui OUGI_CORE + complete EVT236 sequence identifies the exact state/op boundary before any further mutation.
